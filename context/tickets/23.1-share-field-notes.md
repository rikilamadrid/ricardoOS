# Share Localized Field Notes

## Status

In Progress

## Parent Feature

`23-field-notes-distribution.md`

## Blocked by

None

## Goal

Give every localized Field Note a calm, accessible share control whose native
and fallback actions all distribute the correct canonical article URL.

## Context

- Read: `context/features/23-field-notes-distribution.md`, `CLAUDE.md`,
  `src/lib/site.ts`, `src/data/types.ts`,
  `src/components/content/WritingPostContent.tsx`,
  `src/app/writing/[slug]/page.tsx`,
  `src/app/writing/[slug]/[locale]/page.tsx`,
  `src/app/writing/[slug]/opengraph-image.tsx`, and the content-page styles in
  `src/app/globals.css`.
- Relevant area: localized article routes, article metadata, reusable content
  controls, and the static Open Graph export.

## Changes

- Add localized, data-driven share labels/messages and one canonical helper
  that derives an absolute URL from `SITE_URL`, slug, and locale without query
  strings or fragments.
- Add short localized share copy to Field Note metadata. Pass it to native
  sharing and Bluesky; copy it on LinkedIn activation with a selectable manual
  fallback that never blocks the LinkedIn destination.
- Add a reusable `ShareActions` client component near the article date/tags.
  Use native Web Share only after feature detection and direct user activation;
  ignore cancellation and communicate other failures accessibly.
- Keep Copy Link reachable on every browser. Use the Clipboard API when
  available, announce success, and reveal a selectable canonical URL with
  localized instructions when automatic copying fails.
- Add explicit LinkedIn and Bluesky share actions with safely encoded article
  text/URL and safe external-window behavior. Load no social SDK and contact no
  social origin before activation.
- Match the existing glass/content-page presentation with visible focus,
  keyboard operation, dark/light support, and reduced-motion behavior. Do not
  add a popup on load, sticky affordance, or repeated share CTA.
- Preserve existing article metadata and OG generation, and add the appropriate
  human-readable `[Unreleased]` changelog entry when implementing the slice.

## Verification

- Run `npm run lint` and `npm run build`; both pass and all existing localized
  Field Note routes and OG image routes remain in the static export.
- On representative English, Spanish, and French article routes, verify the
  shared/copied URL exactly matches that route's clean absolute canonical URL.
- Exercise supported and unsupported native-share states, native cancellation,
  a genuine native-share failure, Clipboard success, and Clipboard rejection;
  fallbacks remain usable and status/error messaging is accessible.
- Confirm native share data and Bluesky include the localized caption. Confirm
  LinkedIn opens whether caption copying succeeds or fails, with localized
  feedback and a selectable manual caption after failure.
- Operate every action by keyboard, confirm visible focus and screen-reader
  labels/status, and confirm reduced-motion mode does not hide state.
- Inspect exported metadata/page source and the referenced image file, then run
  a share-preview check for a representative post; title, description, URL,
  and preview image match the article.

## Out of Scope

- Newsletter signup/privacy work, additional social networks, social SDKs,
  authentication, counters, analytics, and automated posting.
